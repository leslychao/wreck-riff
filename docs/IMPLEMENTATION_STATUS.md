# Состояние версии 0.4

Реализуется утверждённый [план 0.4](V0_4_PLAN.md): помощь напалму, четыре удара
баллистики, рикошетящее ядро, тяжёлые физические попадания, трёхсекундные
физические остовы, усиленные повреждения кузова, эффекты и записанные звуки.
