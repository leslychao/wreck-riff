# Интеграция арен и релизной версии

Статус: реализация утверждённого RELEASE_PLAN.md продолжается. Этот документ не подтверждает релизную приёмку.

- Стек проверен по build.gradle: один Java 21 Gradle-проект, jME 3.8.1-stable, Minie 9.0.3, Gson 2.13.1. Единственный PhysicsWorld вызывает ручной шаг 120 Гц; gravity = 18 м/с².
- Используется Microsoft JDK C:\Users\vitalii\.jdks\ms-21.0.11. Проверки: gradlew.bat test physicsTest verifyAssets; итоговая чистая проверка и packageWindows выполняются после интеграции.
- Configs строго проверяет поля record и читает локальные config/*.json. Пользовательский progress требует отдельной миграции и не проходит через строгий контракт bundled config.
- Арсенал задан CombatRules/WeaponType и config/combat.json. Независимый пулемёт, Homing, Power, Mine, Napalm, Ballistic, Cannon; Freeze и Shield. Новое оружие не входит в задачу.
- Исходный Rivet: 4,6 × 2,1 м в плане, масса 1100 кг, составная форма и четыре raycast-колеса. Высота native compound не равна одному декоративному параметру; профиль должен сохранять фактическую форму Rivet.
- ArenaSystems выдаёт Repair 25% максимума, Homing +3, Power/Mine/Napalm/Cannon +2, Ballistic +1, Turbo +50. Новые интервалы сокетов меняют только конфигурацию новых арен.
- До изменения транзакций результат записывается синхронно через SettingsStore. Целевой владелец статистики и кампании — ProgressStore, одна атомарная запись неизменяемого снимка вне физического шага.
- Рабочая копия на старте уже содержала изменения документации, CombatRules/CombatSystem/config/combat.json, BotController и связанных тестов. Они сохранены. Сохраняется уточнённый владельцем контракт сильного Cannon и причинно подтверждённого аварийного recovery; старый результат seed=8 не используется как актуальный диагноз.
- Новые исходники и правки текущей задачи ещё не являются доказательством проходимости, визуального качества, FPS или работоспособности финального ZIP. Эти проверки перечислены в RELEASE_PLAN.md.
