# История удалённых глав кампании

Здесь сохранены оригинальные normal/boss WAV для `ash_necropolis` и `doomsday_arena`,
первоначальный генератор, его source hash, полный исходный manifest, метрики и партитура.
Этот каталог не является ресурсным каталогом игры и не копируется в runtime.

Шесть используемых WAV для стройки, неона и карнавала остаются в `audio/campaign`.
После удаления двух тем активный генератор был повторно запущен на NumPy 2.3.5;
хеши шести используемых WAV совпали с первоначальным manifest byte-for-byte.
`VerifyAssets` проверяет исходный рецепт и точные хеши четырёх архивных WAV и
отклоняет их присутствие в runtime classpath.

Также сохранены два исходных звука падающей статуи и соответствующий manifest.
`GenerateAudio-before-statue-retirement.java.txt` воспроизводит точный source hash
этого manifest. Этот промежуточный рецепт уже ограничен тремя музыкальными парами,
но ещё содержит удалённый синтез статуи. Оба звука и их рабочие потребители удалены
из поставляемого звукового набора; оригиналы проверяются отдельно как история.

В `runtime` сохранены исходники до удаления статуй, ритуала, управляющего щита и
световых тем двух прежних глав. Они имеют расширение `.java.txt`, не компилируются
и не участвуют в загрузке игры. Действующий `ArenaHazardSchedule` обслуживает только
авторские опасности и перекрытия; разрушение панели сразу открывает её проезд.
